# ULauncher

Лаунчер Minecraft: Java Edition зі збірками, модами, шейдерами, ресурспаками та модпаками.

## Запуск

Двічі клацніть **`Запустити ULauncher.bat`** або в терміналі:

```powershell
npm start
```

## Можливості

- **Вхід через Microsoft**: лаунчер працює лише після входу в акаунт із ліцензією Minecraft.
- **Офлайн-нік**: після входу в «Акаунт» можна перемкнутися на режим «Офлайн-нік» і грати під будь-яким ніком.
  Він працює в одиночній грі, у LAN і на серверах з `online-mode=false`. На ліцензійних серверах потрібен режим «Ліцензія».
- **Збірки**: кожна збірка має свою версію гри, лоадер (Vanilla / Fabric / Quilt / Forge / NeoForge) і свою папку
  (моди, світи, налаштування). Файли самої гри спільні для всіх збірок, тому вдруге нічого не завантажується.
- **Каталог Modrinth**: пошук і встановлення модів (разом з обов'язковими залежностями), шейдерів і ресурспаків,
  відфільтрованих під версію збірки. Моди можна вмикати, вимикати й видаляти. Також можна додати власні файли.
- **Шейдери**: лаунчер підкаже й одним кліком встановить Iris (або Oculus для Forge).
- **Модпаки**: встановлення з Modrinth або імпорт файлу `.mrpack`. Кожен модпак стає окремою збіркою.
- **Java встановлюється сама**: лаунчер завантажує офіційну Java від Mojang потрібної версії.

## Де лежать дані

`%APPDATA%\.ulauncher`

- `shared/`: версії, бібліотеки та ассети гри (спільні для всіх збірок)
- `instances/<збірка>/`: `mods`, `shaderpacks`, `resourcepacks`, `saves`, `config`…
- `runtimes/`: Java
- `config.json`: налаштування. Токен Microsoft зберігається зашифрованим засобами Windows.

## Примітки

- Forge і NeoForge встановлюються їхніми офіційними інсталяторами (Forge підтримується для 1.13+).
  Ця частина експериментальна: якщо щось не запускається, подробиці буде видно в «Консолі».
- CurseForge не підтримується, бо його API потребує приватного ключа. Увесь каталог береться з Modrinth.
